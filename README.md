AI Resume Screening System (NLP)

📌 Overview

This project automates resume screening by matching resumes with job descriptions using Natural Language Processing (NLP). It helps recruiters quickly identify the best candidates.

🚀 Features

* Resume and job description matching
* Text preprocessing and cleaning
* TF-IDF feature extraction
* Cosine similarity-based ranking system
* Keyword extraction and skill gap analysis

🛠️ Tech Stack

* Python
* NLP (NLTK / Scikit-learn)
* TF-IDF Vectorizer
* Cosine Similarity

📊 Process

1. Text Preprocessing (tokenization, stopword removal)
2. Feature Extraction using TF-IDF
3. Similarity Calculation using Cosine Similarity
4. Ranking resumes based on relevance

📈 Results

* Efficient resume ranking system
* Identified skill gaps between resumes and job roles

▶️ How to Run

1. Clone the repository
2. Install dependencies
3. Run the main script
